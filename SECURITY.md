# Security policy

Recos Diet is a static website: it stores no data, has no accounts and no cookies, and what you enter (weight,
height, pathologies) never leaves your browser. What is at stake security-wise is the accuracy of the recommendations
it displays.

## Reporting a vulnerability

Do not describe it in a public issue: use the "Report a vulnerability" button in the
[Security](https://github.com/recos-diet/recos-diet/security) tab of the repository. The report stays private until
it is fixed.

In scope, among others:

- any way to alter what https://recos-diet.yann-disanto.com serves (pages, data, scripts);
- a flaw in the delivery chain (GitHub Actions workflows, deployment);
- a vulnerable dependency that can actually be exploited on the site.

A clinical recommendation you believe is wrong is not a vulnerability: open an
[issue](https://github.com/recos-diet/recos-diet/issues).

## Response times

The project is maintained by a single volunteer: you will get an answer as soon as possible. Only the version in
production gets fixes.
